- **왜 이 배치인가:** 스타크래프트 관례(왼쪽 팔레트, 오른쪽 미니맵·속성, 아래 부가 정보)를 그대로 따른다. 기획자가 그 툴을 안다는 가정이 벤치마크의 전제다.
- 캔버스가 항상 가장 크다. 패널은 접힌다. 창 폭 1280 이하에서는 하단 탭이 자동으로 접힌다.
- **하단 패널 높이는 드래그로 바꾼다** (2026-09-06). 하단의 윗변이 손잡이이고, 위로 끌면 커진다.
  더블클릭하면 기본값 200px. 값은 `localStorage` 에 남아 다음에 열 때도 유지된다.
  최소 72px — 탭 줄이 잘리면 탭을 못 고른다. 최대는 캔버스에 160px 을 남긴 만큼 —
  캔버스가 사라지면 손잡이를 되돌릴 단서가 화면에서 없어진다.
  구현은 `--bottom-h` 변수 하나만 바꾸고 캔버스는 `ResizeObserver` 로 따라온다 (SDD-08 §11).
- 상단 바의 `*` 는 저장 안 된 변경. 창을 닫으려 하면 `beforeunload` 로 막고 묻는다.
- **상단 바 오른쪽 버튼 (2026-09-06 확정):** `새로 만들기` · `열기` · `저장` · `다른 이름으로 저장` · `TOON 복사` · `?`
  `새로 만들기` 는 `createEmptyStage(name, 32, 18)` — 게임 격자와 같은 크기로 시작하고, 바꾸려면 맵 탭의 `크기 변경`.
  누르기 전에 저장 안 된 변경이 있으면 묻는다. **Undo 로 되돌아가지 않는다** — `history.replace` 가 스택을 비운다.
  초안도 함께 지운다. 새 문서를 열었는데 다음에 옛 초안 복구를 물으면 혼란스럽다.
  `열기` 는 목록에 없었지만 **뺄 수 없다** — 기획자가 zip·메일로 받은 `.toon` 을 여는 유일한 길이고,
  `Ctrl+O` 만 남기면 찾지 못한다 (숨은 조작이 안 통한다는 것을 지름길에서 이미 배웠다).

## 2. 팔레트 `[D-03-02]`

번호 순서는 **쓰는 빈도** 순이다 (현재 맵은 B 381 / R 51 / W 36 / ~ 10 / V 2 / . 0 / _ 96).

| 키 | 셀 | 표시 |
|---|---|---|
| 1 | Buildable `B` | 게임 색 사각 |
| 2 | Road `R` | |
| 3 | Blocked `W` | |
| 4 | Water `~` | |
| 5 | VillageSlot `V` | + 마을 마커 미리보기 |
| 6 | Ground `.` | |
| 7 | Empty `_` | 배경색 + 점선 테두리 (안 그러면 안 보인다) |
| — | 지우개 | `Delete` 가 선택 영역에 칠하는 셀. **기본 Buildable** |

**왜 지우개가 Buildable 인가:** "지운다" 의 의미가 이 맵에서는 "다시 평범한 땅으로" 이고, 평범한 땅은 Buildable 이다 (381/576). Empty 로 지우면 맵에 구멍이 나고 Ground 로 지우면 배치 불가 칸이 생긴다.

**우클릭 지우개는 폐지됐다 (2026-09-06, ADR-E12).** 팔레트에 칸 7종이 다 있으므로 "지우기" 는 다른 칸으로 덧칠하기와 같은 일이었고, 같은 결과를 내는 조작이 둘이면 배울 것만 늘었다. 우클릭 자리는 컨텍스트 메뉴가 쓴다 (§3). 지우개 셀은 `Delete` 에만 남았고, 지금은 바꿀 UI 가 없다 — 필요해지면 **화면에 보이는** 형태로 넣어라. 숨은 조작으로 되돌리지 마라.

## 3. 도구 `[D-03-03]`

전부 `ui/input/tools/*.ts` 의 상태기계. 입력은 커맨드로만 문서를 바꾼다 (SDD-01 §3).

| 도구 | 키 | 동작 | 커맨드 |
|---|---|---|---|
| 브러시 | `B` | 드래그로 칠한다. 크기 1·3·5 (`[` `]`). **Shift+클릭 = 직전 점에서 직선** (스타크래프트 관례) | `PaintCells` (스트로크당 1개) |
| 선 | `L` | 두 점 사이 Bresenham. 도로 긋기용 | `PaintCells` |
| 사각 | `R` | 드래그 사각형 채우기. Shift 로 정사각. Alt 로 테두리만 | `FillRect` |
| 채우기 | `F` | 같은 셀 4-연결 영역을 플러드필 | `FloodFill` |
| 선택 | `M` | 사각 영역 선택 → 복사/잘라내기/붙여넣기/삭제(=지우개 셀로). 붙여넣기는 커서 따라다니는 고스트를 놓아 확정 | `PasteCells` |
| 스포이드 | `I` (또는 Alt+클릭) | 클릭한 셀을 현재 팔레트로 | — |
| 노드 | `N` | 빈 곳 클릭 = 노드 추가(id 자동: 빈 번호 중 가장 작은 `Nxx`), 노드 드래그 = 이동, Delete = 삭제 | `AddNode` `MoveNode` `DeleteNode` |
| 엣지 | `E` | 노드 클릭 → 노드 클릭 = 엣지. 두 번째를 **Shift+클릭**하면 지름길(allowed=Escortee, **단방향** — ADR-E11) | `AddEdge` |
| 오브젝트 | `V` | 마을·노드·엣지·시작·탈출을 클릭해 선택 → 속성 패널. Ctrl+클릭 다중 선택 | 속성 패널이 커맨드를 낸다 |

**도로에서 경로 만들기 (경로 탭 버튼, 2026-09-06).** `start` 셀에서 `exit` 셀까지 도로(`R`)를 BFS 로
따라가며 **꺾이는 칸마다 노드**를 찍고 축 정렬 엣지로 잇는다 (`core/geometry/roadpath.ts`).
코너를 손으로 찍으면 한 칸씩 어긋나 V-P03 이 터지는데, 그 실수를 기계가 없앤다.
만든 결과는 그 자체로 V-P03 을 만족한다(테스트가 지킨다).

- **런타임 추론이 아니다.** 게임은 도로에서 그래프를 추론하지 않는다 — 명시적 금지다:
  *"노드 자동 생성(Road 타일에서 그래프를 추론)을 만들지 마라. 분기와 지름길을 표현할 수 없다"*
  (게임 `TASKS-P1-prototype.md:568`). 여기서 만든 것은 파일에 **명시적 노드·엣지로 저장**되고
  기획자가 그 위에 분기·지름길을 얹는다. 게임 쪽은 한 줄도 바뀌지 않는다.
- **분기·지름길은 만들지 않는다.** 도로 칸만 봐서는 알 수 없다 — 분기 노드는 도로 **밖**에 있고
  (`B01_branch`), 지름길은 어느 구간인지 도로에 적혀 있지 않다.
- 경로를 **통째로** 갈아끼운다. 무엇이 사라지는지(분기 N개·지름길 M개·고아가 될 트리거)를
  확인 대화상자에 먼저 적고 받는다. `burst.triggerNodeIds` 는 건드리지 않는다 — 없는 노드를
  가리키게 되면 V-P01 이 잡아 준다. 조용히 지우면 트리거를 잃은 줄도 모른다 (ADR-E08 의 정신).
- Undo 한 번에 통째로 되돌아간다.

**우클릭 컨텍스트 메뉴 (2026-09-06, ADR-E12).** **도구와 무관하게** 열린다. 메뉴 내용은 커서 아래에 무엇이 있느냐로만 정한다 — 도구에 따라 우클릭이 달라지면 예측할 수 없다(실제로 한 번 그렇게 만들었다가 바로 걸렸다). `ui/panels/contextmenu.ts`.

| 우클릭 대상 | 항목 |
|---|---|
| 노드 | 이름 바꾸기(참조 갱신) · 역할 4종 · 버스트 트리거 지정/해제 · 삭제(붙은 엣지·트리거 함께) |
| 엣지 | 지름길 만들기/해제 · 단방향↔양방향 · 삭제 |
| 빈 칸 | 노드 추가 · **시작점** · **탈출점** · 노드 추가 + 가장 가까운 노드와 잇기 |

**지름길은 두 점만 고른다.** 노드 우클릭 → `여기서 지름길 시작` → 다른 노드 우클릭 →
`여기로 지름길 잇기`. 대기 중에는 메뉴 제목에 `[지름길: N05 → ?]` 가 뜨고 `Esc` 로 취소된다.
`E` 도구의 Shift+클릭도 같은 일을 하지만 그건 숨은 조작이라 아무도 찾지 못했다 (2026-09-06).

- **지름길은 도로를 따라가지 않는다.** 도로 밖으로 질러가는 새 연결이므로 축 정렬 검사(V-P03)는
  비지름길 엣지만 본다. 그래서 "출발점·도착점만 정하면 나머지는 직선" 이 맞는 동작이다.
- 이어지는 엣지는 `allowed=Escortee`(V-P04) + 단방향(V-P10, ADR-E11) 로 **함께** 만들어진다.
- 이미 엣지가 있는 두 노드를 고르면 거절하고 이유를 말한다 — 중복 엣지는 V-P08 이 거부한다.
  그 경우 기존 엣지를 우클릭해 `지름길로 만들기` 를 쓰면 된다.
- 개방은 게임이 한다: 구매 → `PathGraph.OpenShortcut` → `OnGraphChanged` → 보호대상 경로 재계산
  (`ShortcutController.cs:13`). 툴은 **어느 연결이 지름길인가** 만 정한다.

- 지름길을 켤 때 `allowed=Escortee` 와 단방향을 **함께** 준다. 하나만 주면 툴이 자기 규칙(V-P04·V-P10)을 어기는 문서를 만든다.
- 시작점을 새로 놓거나 지정하면 **기존 시작점을 같은 스트로크에서 경유로 내린다.** `start` 는 정확히 1개여야 하고(V-P02 ❌), 두 개가 된 채로 두면 기획자는 왜 빨간 줄이 떴는지 모른다. Undo 한 번에 둘 다 되돌아간다.
- 탈출점은 강등하지 않는다 — 여러 개는 ⚠️ 이고 게임이 첫 번째만 쓴다 (`Escortee.cs:63`).
- **출발점·도착점에 별도 오브젝트를 만들지 마라.** 노드의 `role` 이다 (ADR-E05: 같은 사실을 두 곳에 두지 않는다). 보호대상과 모체는 같은 `start` 셀에서 출발한다.

- 브러시가 `V` 를 칠할 때는 **크기를 1 로 강제** 한다. 마을은 셀 하나다.
- 셀을 칠해서 노드 아래 도로가 사라지면 그 자리에서 V-P07/V-P03 마커가 뜬다. 칠하기를 막지는 않는다 — 기획자가 도로를 옮기는 중일 수 있다.
- 노드 자동 id 는 `N%02d` 에서 비어 있는 가장 작은 번호. 이름은 이후 기획자가 바꾼다 (`RenameNode`, 참조 갱신 포함). **기존 노드 번호는 절대 바뀌지 않는다** (ADR-E06).

## 4. 레이어와 미니맵 `[D-03-04]`

| 레이어 | 기본 | 내용 |
|---|---|---|
| 타일 | 켜짐 | 셀 색 |
| 격자 | 켜짐 (`G`) | 셀 경계 + 5칸마다 굵은 선 + 가장자리 좌표 눈금 |
| 경로 | 켜짐 | 노드(시작 흰색·탈출 금색·그 외 회색)·엣지·**화살촉은 단방향 엣지에만**·지름길 노란 점선·트리거 노드(⚡) |
| 오브젝트 | 켜짐 | 마을 마커(1.4셀 사각) · 시작(하트+모체 사각) · 탈출(노란 테두리) — 게임 그대로 |
| 도달 영역 | 켜짐 (`H`) | 마을별 색으로 도달 가능한 `B` 를 옅게 칠하고, 도달 불가 `B` 는 빗금. **끄더라도 상태줄 숫자는 남는다** |
| 검증 마커 | 켜짐 | 오류 셀·노드·엣지에 빨간/노란 테두리. 클릭하면 검증 탭의 해당 항목으로 |

**검증 마커 구현 (2026-09-06).** `issue.cells` 는 칸 테두리, `issue.nodeIds` 는 노드 둘레 고리,
`issue.edgeIndex` 는 엣지 선을 굵게 덧그린다 (`ui/canvas/renderer.ts`). ❌ 빨강 · ⚠️ 노랑.
**ℹ️ 는 그리지 않는다** — V-M06 은 상시 발화라 늘 켜져 있게 되어 신호가 죽는다.
한 대상에 이슈가 여럿이면 더 심한 쪽을 쓴다. `검증` 레이어를 끄면 마커도 꺼진다.

**경로 정리 (왼쪽 패널, 2026-09-06).** `도로 밖 노드 삭제` — 도로(`R`) 위가 아닌 노드를 찾는다.
패널에 `도로 밖 N개 (위반 x · 분기 y)` 를 늘 표시한다.
**분기 노드를 위반과 섞지 마라.** 분기는 원래 도로 밖에 두는 것이다 (SDD-02 §3-1, 씨앗의
`B01_branch` 는 Buildable 위). 대화상자가 둘을 갈라 보여 주고 `[규칙 위반만] [전부] [취소]` 를 준다.
지우면 붙은 엣지와 버스트 트리거 참조도 함께 사라진다 — 대화상자에 적는다. Undo 한 번에 전부 복구.
| 시뮬 | 꺼짐 | 궤적·현재 위치·버스트 구간 (SDD-04) |

미니맵: 타일 레이어 축소 + 뷰포트 사각형 + 노드 점. 클릭/드래그로 뷰 이동. 맵이 한 화면에 다 들어오면(32×18 기본 줌) 미니맵은 그래도 보인다 — 맵이 커질 계획(ADR-0014)이라 처음부터 있다.

## 5. 오브젝트 계층 `[D-03-05]`

파일에는 `objects` 섹션이 없다 (SDD-02 §8). 그래도 기획자 눈에는 "마을을 옮긴다", "출구를 옮긴다" 가 셀 칠하기와 다른 동작이어야 한다. 그래서 **UI 에서만** 오브젝트로 다룬다.

| 오브젝트 | 실체 | 선택하면 속성 패널에 | 옮기면 |
|---|---|---|---|
| 마을 | `V` 셀 | 좌표, 이 마을에서 도달 가능한 B 수 | 옛 셀은 지우개 셀로, 새 셀은 `V` (커맨드 하나) |
| 시작 | `role=start` 노드 | 노드 속성 + "보호대상·모체가 여기서 출발" 안내 | 노드 이동 |
| 탈출 | `role=exit` 노드 | 노드 속성 + 2개 이상이면 "게임은 첫 번째만 씀" 경고 | 노드 이동 |
| 노드 | `PathNode` | id(편집→rename), role, 버스트 트리거 체크, 붙은 엣지 목록 | 드래그 |
| 엣지 | `PathEdge` | allowed 체크 3개, 양방향, 지름길(켜면 allowed 가 Escortee 로 잠김) | — |

## 6. 하단 탭 `[D-03-06]`

| 탭 | 내용 |
|---|---|
| 맵 | 이름, 크기(→§7), 셀 통계표(종류별 개수·비율), 도달 영역 요약(마을별) |
| 경로 | 노드 표(id·x·y·role·트리거) + 엣지 표. 행 클릭 = 캔버스 선택. 여기서도 편집 가능 |
| 스폰 | 리듬(묶음·간격·휴지·예고) + **파생값 즉시 표시**: 사이클 초, 마리/초 (`SpawnCycleSeconds`/`NormalSpawnRate` 와 같은 식) · 스폰 표(적 이름 콤보+직접 입력, 가중치, 비율 %) · 체력 곡선 표(t, mul) + 작은 그래프 · 버스트(트리거 노드 콤보, 지속, 묶음, 휴지, 회복 배속, 회복 초) |
| 밸런스 | 경제(시작 자원, 지름길 비용, 난이도 표 3행 고정) · 보호대상 · 모체 · 연출 · 토글 — 전부 라벨 한국어 + 툴팁에 게임 필드명 |
| 검증 | 규칙 ID·심각도·메시지 목록. 클릭 = 캔버스 포커스. 상단 바 배지가 개수 |

숫자 입력은 `<input type=number>` + 범위를 placeholder 로. 범위 밖이면 즉시 빨간 테두리 (V-S03). 값은 `blur`/`Enter` 에 커맨드 하나로 확정 — 키 한 번마다 히스토리에 쌓이면 Undo 가 쓸모없어진다.

## 7. 맵 크기 변경 `[D-03-07]`

- 다이얼로그: 새 폭·높이 + **앵커 9칸** (좌상·상·우상·좌·중·우·좌하·하·우하). 스타크래프트엔 없지만 Tiled·Aseprite 관례.
- 잘려 나가는 셀 수, **맵 밖으로 나가는 노드 목록** 을 확정 전에 보여 준다. 나가는 노드는 지우지 않고 그대로 두어 V-P07 로 잡히게 한다 — 조용히 지우면 엣지·트리거가 같이 사라져 원인을 못 찾는다.
- 새로 생기는 셀은 `Empty`. `origin` 은 앵커에 맞춰 조정한다 (게임 월드 좌표의 중심을 유지하려면 좌하 앵커일 때만 origin 이 그대로다 — 툴팁으로 설명).
- 커맨드 하나 (`ResizeMap`), Undo 가능.

## 8. 단축키 `[D-03-08]`

표는 고정이다. 바꾸면 기획자 손이 어긋난다.

**툴 안에 도움말 오버레이가 있다** — `?` 또는 `F1`, 상단 바 `?` 버튼. `src/ui/panels/help.ts`.
2026-09-06 첫 배포 후 "단축키를 하나도 모르겠다" 는 피드백을 받아 넣었다. 별도 문서로 두지 않는
이유는 문서가 툴과 같이 움직이지 않기 때문이다.
**오버레이에는 실제로 동작하는 키만 적는다.** 없는 키를 적으면 기획자가 자기 손을 의심한다.

아직 구현되지 않아 오버레이에서 뺀 것 (2026-09-06): `Ctrl+Shift+S`(다른 이름으로 — 버튼은 있다),
`Ctrl+Enter`(시뮬 실행), `Tab`(하단 탭 순환), `Ctrl+B`(하단 패널 접기).

| 키 | 동작 |
|---|---|
| `1`~`7` | 팔레트 (§2 순서) |
| `B` `L` `R` `F` `M` `I` `N` `E` `V` | 도구 (§3) |
| `[` / `]` | 브러시 크기 − / + |
| 좌클릭 | 칠하기 |
| 우클릭 | 컨텍스트 메뉴 (도구와 무관, ADR-E12) |
| Shift+클릭 | 직전 점에서 직선 (브러시) · 정사각(사각) · 지름길(엣지) |
| Alt+클릭 | 스포이드 |
| 휠 | 줌 (커서 기준). `Ctrl+0` 화면 맞춤, `Ctrl+1` 100% |
| Space+드래그 / 중클릭 드래그 | 팬 |
| `Ctrl+Z` / `Ctrl+Y` (`Ctrl+Shift+Z`) | Undo / Redo |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` `Delete` | 선택 영역 복사·잘라내기·붙여넣기·지우기 / 노드·엣지 삭제 |
| `Esc` | 선택 해제 · 진행 중 드래그 취소 · 다이얼로그 닫기 |
| `G` / `H` | 격자 / 도달 영역 토글 |
| `Ctrl+S` `Ctrl+O` `Ctrl+Shift+S` | 저장 · 열기 · 다른 이름으로 |
| `Ctrl+Shift+C` | TOON 복사 |
| `Ctrl+Enter` | 시뮬 실행 (F5 는 브라우저 새로고침이라 쓰지 않는다) |
| `Tab` | 하단 탭 순환. `Ctrl+B` 하단 패널 접기 |

브라우저 기본 동작과 겹치는 키(`Ctrl+S`, `Ctrl+O`)는 `preventDefault` 한다. 입력 필드에 포커스가 있을 땐 문자 단축키를 무시한다.

## 9. 검증 패널과 저장 `[D-03-09]`

- 문서가 바뀌면 100ms 뒤 검증이 돌고 배지·마커·목록이 갱신된다.
- **저장은 오류가 있어도 된다** (ADR-E08). 저장 시 오류가 있으면 (1) 파일 첫 주석에 `# ⚠ 검증 실패 N건 — 임포트되지 않는다` 를 넣고 (2) 다이얼로그로 알린다. 막지 않는 이유: 기획자가 반쯤 그린 맵을 저장 못 하면 브라우저 탭이 닫히는 순간 작업이 사라진다. 임포터가 막으니 게임은 안전하다.
- `TOON 복사` 도 같다. LLM 에게 "이 맵의 문제를 고쳐 줘" 라고 물을 때 오류 주석이 오히려 도움이 된다.

## 10. 첫 실행 경험 `[D-03-10]`

- 파일을 열지 않은 상태에서는 **씨앗(`Stage_Greybox`)이 내장** 되어 있어 바로 보인다. 빈 32×18 도 "새로 만들기" 로 가능.
- 처음 열면 짧은 안내 오버레이 (팔레트·도구·저장 세 가지만). 두 번째부터는 안 뜬다 (localStorage).
- 설명서는 따로 쓰지 않는다. **S-04 기획자 왕복 검증 (SDD-07 M6)** 에서 설명서 없이 되는지가 판정 기준이다.
