# ADR-E07. 시뮬레이션은 **천장** 만 계산한다 — 전투·승패는 계산하지 않는다

- 상태: 채택 · 2026-09-03 · 사용자 확정 범위 "툴 내 시뮬레이션 미리보기"
- 관련: SDD-04 전체 · 게임 Serena 메모리 `balance_measurement_harness`, `difficulty_and_economy`

## 결정

시뮬은 보호대상·모체·스폰 리듬·적 이동만 돌린다. 아군 배치, 사격, 피해, 처치, 보호대상 체력, 승패는 **없다.**
출력은 판 길이 · 총 스폰 · 수입 천장 · 모체 거리 곡선 · 버스트 창 · 접촉 시각.

## 이유

게임 프로젝트가 2026-09-02 자동 플레이 시뮬로 밸런스를 판정하려다 **세 번 틀렸다**:
무적 플래그가 다음 시뮬로 새어 "승리" 로 오판, 틀린 마을을 잡음, 그리고 시뮬이 애초에 사람 수준으로 플레이하지 못해 스폰 3↔4 의 차이를 구분 못 함.
그 결론: *자동 계측으로 믿을 수 있는 것은 총수입 상한·처치량·판 길이·동시 생존 peak 까지. 승패·병종 우열·"할 만하다" 는 사람이 판정한다.*

전투를 넣으면 툴이 "이 배치로는 이긴다" 는 한 가지 사실을 내고, 그것이 밸런스 판단으로 오독된다. **믿을 수 없는 숫자를 보여 주는 것보다 안 보여 주는 게 낫다.**

이 제약 덕분에 시뮬은 결정론적이고(시드 PRNG) 밀리초에 끝나며, 게임 실측(402 / 56기 / 119초)과 대조할 수 있는 회귀 테스트가 된다.

## 대가

- "이 맵이 어렵나" 는 여전히 사람이 플레이해서 안다. 툴은 "이 맵에서 최대 얼마를 벌 수 있나" 만 답한다.

## 되돌리기

전투를 넣고 싶으면 별도 ADR 로, 그리고 **결과 화면에 "승패는 참고용" 을 박는 조건** 으로만.
