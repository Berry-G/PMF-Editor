# ADR-E08. 검증에 실패해도 **저장은 된다.** 거부는 임포터가 한다

- 상태: 채택 · 2026-09-03
- 관련: SDD-03 §9 · SDD-05 §6 · SDD-02 §5

## 결정

툴은 오류가 있어도 `.toon` 을 저장하고 `TOON 복사` 를 허용한다. 대신 (1) 파일 첫 주석에 `# ⚠ 검증 실패 N건 — 임포트되지 않는다` 를 쓰고 (2) 다이얼로그로 알린다.
Unity 임포터는 ❌ 가 하나라도 있으면 **에셋을 건드리지 않고** 중단한다.

## 이유

- 기획자가 반쯤 그린 맵을 저장하지 못하면 브라우저 탭이 닫히는 순간 작업이 사라진다. **작업 손실이 잘못된 데이터보다 나쁘다.** 잘못된 데이터는 임포터가 막으니 게임은 안전하다.
- 같은 규칙을 두 번(툴·임포터) 돌리는 이유가 바로 이것이다: 툴은 *즉시 알려주기* 위해, 임포터는 *툴을 거치지 않은 파일* 을 막기 위해.
- LLM 에게 "이 맵의 문제를 고쳐 줘" 라고 물을 때 오류 주석이 함께 가는 게 오히려 낫다.

## 대가

- 기획자가 경고를 무시하고 넘긴 파일이 개발자에게 올 수 있다. 임포터 로그가 규칙 ID·위치·이유를 찍으므로 되돌려 보내면 된다.
