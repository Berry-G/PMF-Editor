# ADR-E06. 노드 id 는 사람이 읽는 이름이고, 툴은 **절대 재번호하지 않는다**

- 상태: 채택 · 2026-09-03
- 관련: SDD-02 §3-1 · SDD-01 §3-2 (`RenameNode`) · SDD-03 §3

## 결정

- 노드 `id` 는 `^[A-Za-z_][A-Za-z0-9_]*$` 문자열 (`N00_start`, `N06`, `B01_branch`). 문서 안에서 유일.
- 툴은 노드를 지우거나 순서를 바꿔도 다른 노드의 id 를 바꾸지 않는다. 자동 id 는 "비어 있는 가장 작은 `N%02d`" 로만 새 노드에 붙인다.
- 이름 변경은 `RenameNode` 커맨드 하나로, **엣지와 `burst.triggerNodeIds` 의 참조를 함께 갱신** 한다.

## 이유

- 게임이 id 를 **이름 문자열로 정확 일치 매칭** 한다: 노드 GameObject 이름 = id, `_burstTriggerNodeIds` 는 `PathGraph.FindByName` 으로 해석 (`MotherSpawner.cs:142`). 없으면 `LogError` 후 트리거가 조용히 죽는다.
- 1차 계획의 예시가 `N13` 이라 썼지만 실제 이름은 `N13_exit` 다. 이름은 데이터이지 인덱스가 아니다.
- 재번호하는 툴은 "노드 하나 지웠더니 버스트가 안 온다" 는 버그를 만든다. 원인을 파일에서 찾을 수 없다.

## 대가

- 번호에 구멍이 생긴다 (`N03` 을 지우면 `N02`, `N04`). 미관 문제일 뿐이다.

## 되돌리기

없다. 게임이 이름으로 참조하는 한 유지한다.
